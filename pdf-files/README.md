# Folder Modul Ajar

Folder ini berisi file-file modul ajar untuk Pendidikan Jasmani.

## Cara Mengunggah File Modul Ajar:

1. Siapkan file modul ajar dalam format PDF, DOC, atau DOCX
2. Copy file ke folder ini
3. Update file `index.html` untuk menambahkan link download
4. Refresh browser untuk melihat perubahan

## Contoh Struktur Link di HTML:
```html
<a href="modul-ajar/nama-file.pdf" class="download-link" download>
    <i class="fas fa-download"></i> Download Modul Ajar
</a>
```
